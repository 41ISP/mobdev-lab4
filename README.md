# Лабораторная работа №4

## Разработка web-приложения

### Требования

- Минимум 2 экрана
- Минимум 1 API-вызов
- Хотя бы один стор (например, на темную/светлую тему, но по-хорошему туда должна быть зашита бизнес логика приложения)
- Мобильный интерфейс
- Код должен храниться в Github репозитории под названием `mobdev-lab4-{ваша_фамилия}` в организации `41ISP`

### Стек

- [Vite](https://vite.dev/)
- React (TypeScript)
- [Zustand](https://zustand.docs.pmnd.rs)
- [Любой API из этого списка](https://github.com/public-apis/public-apis)
